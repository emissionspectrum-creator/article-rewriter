# 文章改寫工具

本地 WebUI 工具，批次呼叫 Anthropic API 對 `.txt` 檔案進行改寫。每個檔案獨立呼叫 API，不共享對話記錄。

## 需求

- Python 3.8+
- Anthropic API 金鑰

## 安裝與設定

**1. 複製 API 金鑰設定檔**

```
copy .env.example .env
```

以文字編輯器開啟 `.env`，填入你的 API 金鑰：

```
ANTHROPIC_API_KEY=sk-ant-...
```

**2. 啟動**

雙擊 `start.bat`，或在終端機執行：

```
.\start.bat
```

瀏覽器會自動開啟 `http://127.0.0.1:8766`。

## 使用方式

1. 選擇「輸入資料夾」（含 `.txt` 檔案）與「輸出資料夾」
2. 輸入改寫提示詞，或點「載入提示詞檔案」從 `.txt` 讀取
3. 選擇模型
4. 選擇處理模式，按「開始處理」

## 處理模式

| 模式 | 說明 |
|------|------|
| **標準模式** | 逐檔呼叫 API，即時顯示進度。支援 Token 用量警告與暫停功能。 |
| **批次 API** | 一次提交所有檔案，Anthropic 非同步處理，費用省 50%。適合不急著拿結果的大量任務。 |

### 批次 API 注意事項

- 提交後可關閉瀏覽器，批次在 Anthropic 雲端處理
- Batch ID 提交後自動顯示於「查詢批次進度」欄位，並儲存至本地記錄（最近 2 筆）
- 重新開啟程式後，可從歷史記錄點擊填入 Batch ID，再按「查詢進度」或「下載結果」

### 批次結果下載

提交批次時，程式會自動儲存檔名對應記錄（`{batch_id}.map.json`）。下載已完成批次時：

1. 在「查詢批次進度」輸入 Batch ID（或從歷史記錄點擊填入）
2. 填寫「輸出資料夾」
3. 按「下載結果」

> 若是舊批次（無對應記錄），需額外填寫「輸入資料夾」供系統重建檔名對應。

## Token 用量控制（標準模式）

設定累計 Token 警告閾值（預設 100,000），達到後會暫停並詢問是否繼續。勾選「不限制」可停用警告。

## 專案結構

```
article-rewriter/
├── main.py          # FastAPI 後端
├── index.html       # WebUI 前端
├── start.bat        # 一鍵啟動腳本
├── requirements.txt
├── .env             # API 金鑰（不上傳 GitHub）
├── .env.example     # 金鑰設定範本
└── .gitignore
```

## API 金鑰安全

`.env` 已加入 `.gitignore`，不會被上傳至 GitHub。請勿直接將金鑰寫入程式碼。
